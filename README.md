## ⚡ Tech Stack & Architecture

- **Core**: React 19 + TypeScript + Vite
- **Styling**: Neo-brutalist technical design system with responsive glassmorphism, HUD telemetry overlays, and interactive visual components.
- **Key Sections**:
  - `01 / Selected Work`: Elexis-W Wheeled Humanoid, Dynamic F1Tenth Racer, SO-101 Sonomyography Arm, Autonomous Steel Pallet Docking.
  - `02 / Autonomy Lab`: Interactive Isaac Lab multi-agent policy simulation & telemetry console.
  - `03 / About`: Technical background, core values, and embodied AI ethos.
  - `04 / Field Log & Résumé`: Career impact strip, verifiable credentials, and timeline.
  - `05 / Research & Publications`: Preprints, IEEE publications, and academic theses.
  - `06 / Technical Toolkit`: MPC/Whole-body dynamics, RL frameworks, perception pipelines, and physical hardware.
  - `07 / Say Hello`: Direct technical collaboration, prospective research, and contact channels.
  - `08 / My Journey`: Milestone carousel spanning foundational schooling to heavy industry automation, M.Sc. machine learning, IIT Delhi research, and humanoid robotics at Addverb.

## 🛠 Local Development

```bash
# Install dependencies
npm install

# Start Vite local development server
npm run dev

# Build production bundle
npm run build

# Preview production build locally
npm run preview
```
